# 🪙 Coin Runner — เกมวิ่งเก็บเหรียญ + Leaderboard ออนไลน์

เกมวิ่งเก็บเหรียญ เล่นบนเว็บ (คอมและมือถือ) มีระบบจัดอันดับคะแนนออนไลน์ Top 10
ทำงานบน **Vercel** (โฮสต์เว็บ + API) และ **Upstash Redis** (เก็บคะแนน) — ใช้แพ็กฟรีเริ่มต้นได้

## มีอะไรในโปรเจกต์

```
coin-runner/
├── index.html          ← ตัวเกมทั้งหมด (HTML + CSS + JavaScript ในไฟล์เดียว)
├── assets/
│   ├── km.gif          ← รูปตัวละคร (แทนที่ด้วยรูปของคุณได้ ใช้ชื่อเดิม)
│   └── shell.png       ← รูปไอเท็มเก็บคะแนน (เปลือกเต่า)
├── api/
│   └── leaderboard.js  ← API ฝั่งเซิร์ฟเวอร์: ดึง Top 10 / รับคะแนนใหม่
├── package.json        ← บอก Vercel ว่าต้องติดตั้งแพ็กเกจอะไร (@upstash/redis)
├── .env.example        ← ตัวอย่างชื่อตัวแปรลับ (ไม่ต้องสร้างเองถ้าเชื่อมผ่าน Vercel)
├── .gitignore
└── README.md
```

> ⚠️ โฟลเดอร์ **`api`** ต้องอยู่ที่ระดับบนสุดของโปรเจกต์ และไฟล์ต้องชื่อ `leaderboard.js` — Vercel จะสร้างที่อยู่ `/api/leaderboard` ให้อัตโนมัติจากชื่อไฟล์นี้
> ⚠️ โฟลเดอร์ **`assets`** (รูปตัวละครและไอเท็ม) ต้องอัปโหลดขึ้น GitHub ไปด้วย ถ้ารูปหาย เกมจะใช้ภาพวาดสำรองแทน (เล่นได้ แต่หน้าตาจะไม่เหมือนที่ตั้งใจ)

## ระบบในเกม

- **ความเร็วคงที่** ตลอดเกม (ไม่เร่งขึ้น) — ความยากเพิ่มจากอุปสรรคแทน
- **หลอดเลือด** เริ่มที่ 100 · ชนอุปสรรคเสีย 30 (อุปสรรคนั้นแตกหายไป และอมตะ 1.3 วินาที) · เลือดหมด = จบเกม
- **หัวใจ ❤️** เก็บแล้วได้เลือด +25 — สุ่มออกบ่อยขึ้นเมื่อเลือดเหลือน้อย
- **อุปสรรคสุ่มเพิ่มตามเวลาที่เล่น** (ขึ้นระดับใหม่ทุก 15 วินาที):
  | เวลา | สิ่งที่เพิ่มเข้ามา |
  |---|---|
  | เริ่มเกม | กล่องเดี่ยว / กล่องคู่ |
  | 8 วิ | หนามแหลม |
  | 15 วิ | กล่องสูง |
  | 25 วิ | นกบิน (ผ่านเหนือหัว — **ห้ามกระโดด** ตอนนกผ่าน) |
  | 40 วิ | แบบผสม (หนาม+นก, กล่องสามใบ) |
  
  นอกจากนี้ ช่วงพัก (แถวของเก็บล้วน ๆ) จะน้อยลง และระยะห่างระหว่างอุปสรรคจะแคบลงเรื่อย ๆ จนเต็มที่ที่ประมาณ 2 นาที

## 2) นำขึ้น Vercel (ทำตามทีละขั้น)

### ขั้นที่ 1 — สมัครบัญชี (ฟรี)
- GitHub: https://github.com
- Vercel: https://vercel.com → กด **Sign Up → Continue with GitHub** (สะดวกที่สุด)

### ขั้นที่ 2 — เอาโค้ดขึ้น GitHub
วิธีที่ง่ายที่สุด (ไม่ต้องใช้คำสั่ง):
1. คลายไฟล์ `coin-runner.zip` ในเครื่อง
2. บน GitHub กด **New repository** → ตั้งชื่อ `coin-runner` → **Create repository**
3. กดลิงก์ **uploading an existing file**
4. **ลากไฟล์และโฟลเดอร์ทั้งหมด** ที่คลายซิปแล้วไปวาง (ต้องมีโฟลเดอร์ `api` ติดไปด้วย — อย่าอัปโหลดตัวไฟล์ .zip)
5. กด **Commit changes**

### ขั้นที่ 3 — Import เข้า Vercel
1. Vercel Dashboard → **Add New… → Project**
2. เลือก repo `coin-runner` → **Import**
3. **Framework Preset** เลือก **Other** (ปล่อยค่าอื่นไว้ตามเดิม ไม่ต้องใส่ Build Command)
4. กด **Deploy** → รอประมาณ 1 นาที จะได้ลิงก์เว็บ เช่น `coin-runner-xxxx.vercel.app`

ตอนนี้เกมเล่นได้แล้ว แต่ Leaderboard ยังไม่ทำงาน (ต้องมีฐานข้อมูลก่อน)

### ขั้นที่ 4 — เพิ่มฐานข้อมูล (Upstash Redis)
1. ในโปรเจกต์บน Vercel เปิดแท็บ **Storage**
2. เลือก **Create Database** (หรือ **Browse Marketplace**) → เลือก **Upstash → Redis**
3. เลือกแพ็ก **Free** → ตั้งชื่อ → **Create**
4. เมื่อถูกถามให้เชื่อมกับโปรเจกต์ ให้เลือกโปรเจกต์ `coin-runner` (ติ๊กทุก Environment)
5. Vercel จะใส่ตัวแปรลับให้เอง (ชื่อประมาณ `KV_REST_API_URL` และ `KV_REST_API_TOKEN`)
   — โค้ดนี้รองรับทั้งชุด `KV_REST_API_*` และ `UPSTASH_REDIS_REST_*` ไม่ต้องแก้อะไร

> หน้าตาเมนูของ Vercel อาจเปลี่ยนไปเล็กน้อยตามเวลา แต่หลักการเดิม: สร้างฐานข้อมูล Redis แล้วเชื่อมเข้ากับโปรเจกต์

### ขั้นที่ 5 — Redeploy (สำคัญ! มือใหม่มักลืม)
ตัวแปรลับที่เพิ่งเพิ่มจะมีผลกับการ deploy **รอบถัดไป** เท่านั้น:
**Deployments → กดจุดสามจุด (⋯) ที่รายการบนสุด → Redeploy**

### ขั้นที่ 6 — ทดสอบ
1. เปิด `https://ชื่อของคุณ.vercel.app/api/leaderboard` — ควรเห็นข้อความทำนอง `{"top":[]}`
2. เปิดหน้าเกม ใส่ชื่อ เล่นจนจบ → ควรขึ้นว่า "บันทึกแล้ว" และชื่อคุณอยู่ในตาราง Top 10

### (ทางเลือก) Deploy ด้วยคำสั่ง
```bash
npm install -g vercel
cd coin-runner
vercel          # ครั้งแรกจะถามคำถามตั้งค่า ตอบ Enter ตามค่าเริ่มต้นได้
vercel --prod   # ขึ้นเว็บจริง
```

### (ทางเลือก) ทดสอบทั้งระบบในเครื่อง
```bash
npm install
vercel link                  # ผูกกับโปรเจกต์บน Vercel
vercel env pull .env.local   # ดึงตัวแปรลับลงเครื่อง (ห้ามเอาไฟล์นี้ขึ้น GitHub — .gitignore กันไว้ให้แล้ว)
vercel dev                   # เปิดที่ http://localhost:3000
```

## 3) แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุที่น่าจะเป็น | วิธีแก้ |
|---|---|---|
| `/api/leaderboard` ขึ้น 404 | โฟลเดอร์ `api` ไม่ได้ถูกอัปโหลด หรือไฟล์อยู่ผิดที่ | ตรวจใน GitHub ว่ามี `api/leaderboard.js` ที่ระดับบนสุด แล้ว Redeploy |
| ขึ้น `not_configured` / "ยังไม่ได้เชื่อมต่อฐานข้อมูล" | ยังไม่ได้เชื่อม Redis หรือยังไม่ Redeploy | ทำขั้นที่ 4 และ 5 อีกครั้ง |
| ขึ้น 500 / "เซิร์ฟเวอร์ขัดข้อง" | โค้ดหรือฐานข้อมูลมีปัญหา | Vercel → โปรเจกต์ → **Logs** ดูข้อความ error |
| ส่งชื่อไม่ผ่าน | ใช้อักขระที่ไม่รองรับ | ใช้ได้เฉพาะตัวอักษร (ไทย/อังกฤษ) ตัวเลข เว้นวรรค `_ . -` ยาว 1–16 ตัว |
| "คะแนนดูผิดปกติ จึงไม่ถูกบันทึก" (422) | ค่าที่ส่งเกินขีดจำกัดที่เซิร์ฟเวอร์ตั้งไว้ | ถ้าคุณปรับความเร็วเกม ให้แก้ `MAX_METERS_PER_SEC` ใน `api/leaderboard.js` ให้สอดคล้อง |
| แก้โค้ดแล้วเว็บไม่เปลี่ยน | ยังไม่ได้ commit/push | อัปโหลดไฟล์ใหม่ขึ้น GitHub แล้วรอ Vercel deploy อัตโนมัติ (กด Ctrl+F5 เพื่อล้างแคช) |

**เคลียร์ Leaderboard ทั้งหมด:** เปิดฐานข้อมูลใน Upstash Console → Data Browser → ลบคีย์ `coinrunner:leaderboard`

## 4) ปรับแต่งเกมเอง (เริ่มที่ index.html)

ค่าตั้งต้นอยู่ต้นสคริปต์ ใต้หัวข้อ "ค่าตั้งต้นของเกม":

| ค่า | ความหมาย |
|---|---|
| `SPEED` | ความเร็ววิ่ง (คงที่) — ถ้าเพิ่ม ต้องเช็ก `MAX_METERS_PER_SEC` ใน `api/leaderboard.js` ว่ายังสูงกว่า `SPEED ÷ 40` |
| `MAX_HP`, `DAMAGE`, `HEAL`, `INVULN_TIME` | เลือดเต็มหลอด / เลือดที่เสียต่อการชน / เลือดที่ได้จากหัวใจ / เวลาอมตะหลังโดนชน |
| `UNLOCKS` | เวลา (วินาที) ที่อุปสรรคแต่ละชนิดเริ่มโผล่ และข้อความแจ้งเตือน |
| `LEVEL_SECONDS` | ขึ้นระดับใหม่ทุกกี่วินาที |
| `JUMP_V`, `AIR_JUMP_V`, `GRAVITY` | ความสูงและความลอยของการกระโดด |
| `POINTS_PER_COIN` | คะแนนต่อเปลือกเต่า (ต้องแก้ใน `api/leaderboard.js` ให้ตรงกัน) |

แนวคิดต่อยอดสำหรับฝึกเขียน:
- เปลี่ยนรูปตัวละคร/ไอเท็ม: วางไฟล์ใหม่ทับ `assets/km.gif` และ `assets/shell.png` (ควรเป็นพื้นหลังโปร่งใส) — ถ้าสัดส่วนรูปตัวละครต่างจากเดิม (463×571) ให้แก้ตัวเลขใน `SPR_W` ที่ต้นสคริปต์
- เพิ่มอุปสรรคชนิดใหม่ — เพิ่มฟังก์ชันสร้าง (เช่น `addBird`) แล้วเพิ่มรูปแบบใน `spawnPattern()` + `pickPattern()` และวาดใน `drawObstacle()`
- เพิ่มไอเท็มพิเศษ เช่น แม่เหล็กดูดเปลือกเต่า, โล่กันชน 1 ครั้ง
- ทำ Leaderboard แยกรายวัน โดยเพิ่มวันที่ต่อท้ายชื่อคีย์ใน `api/leaderboard.js`

## 5) ข้อควรรู้เรื่องความปลอดภัยและการโกงคะแนน

เกมที่รันในเบราว์เซอร์ผู้เล่น **ไม่มีทางกันการโกงได้ 100%** สิ่งที่โปรเจกต์นี้ทำให้แล้ว:

- เซิร์ฟเวอร์ **คำนวณคะแนนเอง** จากจำนวนเหรียญ + ระยะทาง (ไม่เชื่อค่า "คะแนน" ที่เบราว์เซอร์ส่งมา)
- ตรวจความสมเหตุสมผล เช่น วิ่งได้ไกลสุดต่อวินาที (เกมวิ่งคงที่ 9 ม./วิ, เซิร์ฟเวอร์อนุญาตไม่เกิน 12), เก็บเปลือกเต่าได้มากสุดต่อวินาที
- จำกัดจำนวนครั้งที่ส่งคะแนนต่อ IP (12 ครั้ง/นาที)
- ตรวจและจำกัดรูปแบบชื่อ และแสดงชื่อด้วย `textContent` (กัน XSS)

สิ่งที่ยังเป็นข้อจำกัด:
- คนที่รู้เรื่องโค้ดยังสามารถส่งค่าที่ "ดูสมเหตุสมผลแต่ไม่ได้เล่นจริง" ได้
- ชื่อผู้เล่นไม่มีรหัสผ่าน — ใครใช้ชื่อเดียวกันจะถูกนับเป็นคนเดียวกัน (ระบบเก็บคะแนนที่สูงสุดของชื่อนั้น)
- ยังไม่มีตัวกรองคำหยาบ

ถ้าจะจริงจังมากขึ้น: เพิ่มระบบล็อกอิน, ให้เซิร์ฟเวอร์ออก "โทเคนเริ่มเกม" แล้วตรวจเวลาเล่นจริง, หรือบันทึก replay ของการกดปุ่มไปตรวจซ้ำที่ฝั่งเซิร์ฟเวอร์
